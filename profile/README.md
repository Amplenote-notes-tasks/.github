# Amplenote — Notes + Tasks + Calendar in One Unified Workspace

## About Amplenote

Amplenote combines notes, tasks, and calendar in one unified workspace for productivity professionals, project managers, and deadline‑driven creators. Amplenote integrates jots, rich footnotes, and task scoring. Amplenote supports effort entry, recurring tasks, and tag hierarchies. Amplenote embeds calendar view showing tasks on due dates. Amplenote enables users to capture ideas quickly, turn them into actionable tasks, and schedule them on a timeline. Amplenote is trusted by software engineers, writers, students, and GTD practitioners worldwide.

## Deep Dive — Unified Workspace Features
Jots: inbox‑style quick capture with auto‑reverse chronological sort
Rich footnotes linking to external references or internal notes
Task scoring by urgency + effort matrix (Eisenhower prioritisation)
Recurring tasks with custom intervals (daily, weekly, month day)
Calendar view drag‑drop tasks to dates, see week/month plan
